# Weatherly
Weatherly is an iOS weather application developed as an **individual project for the Code Camp course** at the **University of Kassel**.

The application uses WeatherAPI to display current weather conditions and a three-day forecast for the user's current location or selected cities.

## Features

- Current weather information, including temperature, humidity, wind speed and weather conditions.
- Three day weather forecast.
- Current location detection using Core Location.
- Search for cities and add them to favourites.
- Save and manage favourite locations using SwiftData.
- Switch between Celsius and Fahrenheit.
- Switch between km/h and mph.
- Cache weather data for offline access.
- Save user preferences using UserDefaults.

## Technologies Used

- Swift
- SwiftUI
- WeatherAPI
- Core Location
- SwiftData
- UserDefaults
- URLSession
- JSONDecoder and JSONEncoder
- XCTest

## Running the Project

1. Clone or download this repository.
2. Open `Weatherly.xcodeproj` in Xcode.
3. Make sure the WeatherAPI key is configured in `APIConfig.swift`.
4. Select an iPhone Simulator or connected iPhone.
5. Build and run the project.
